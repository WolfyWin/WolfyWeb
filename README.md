# WolfyWeb 🪐​

![wolfyweb](https://github.com/WolfyWin/WolfyWeb/assets/58392030/ed245870-51ba-4079-a806-448120e4623d)

## 🚀 Aperçu

Portfolio personnel développé en **React**, avec une interface réalisée à l’aide de **Bootstrap** et de composants personnalisés, afin de vous faire découvrir davantage mes projets, mes expériences et mon univers.
<br/>
👉 [Voir le site en ligne](https://www.wolfyweb.fr)

## 🧩 Stack technique

- **React** (front-end)
- **React Router** pour la navigation
- **Bootstrap / React-Bootstrap** pour la mise en page
- **Create React App** pour le build et le serveur de développement
- ✨ Animations et effets visuels réalisés avec plusieurs bibliothèques React (react-spring, react-type-animation, react-tsparticles)
