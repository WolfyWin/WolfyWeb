# WolfyWeb 🪐​

![wolfyweb](https://github.com/WolfyWin/WolfyWeb/assets/58392030/ed245870-51ba-4079-a806-448120e4623d)

## 🚀 Overview

**WolfyWeb** is a personal portfolio built with **React**, featuring a custom interface designed with **Bootstrap** and tailored components.  
It showcases my **projects, experience, and creative universe**, combining technical precision with aesthetic design.  
<br/>
👉 [Visit the live website](https://www.wolfyweb.fr)

## 🧩 Tech Stack

- **React** (front-end)
- **React Router** for navigation
- **Bootstrap / React-Bootstrap** for layout and styling
- **Create React App** for the build process and development server
- ✨ Visual and animated effects implemented with several React libraries (react-spring, react-type-animation, react-tsparticles)
